6-DOF Robotic Manipulator

Designed, simulated, and physically integrated a 6-DOF robotic manipulator (4-DOF arm + 2-DOF independently actuated gripper) as part of the Industrial Robotics curriculum at Ain Shams University. The project bridges the gap between digital twin simulation and real-world micro-ROS hardware actuation.

Key Technical Implementations: • Robot Modeling: Developed a URDF/Xacro model from a SolidWorks assembly, configuring precise link inertias, joint limits, and bounding-box collision properties for physical accuracy. • Simulation & Motion Planning: Integrated the model into Gazebo Sim for dynamic physics testing and tuned PID joint controllers. Leveraged the MoveIt 2 Setup Assistant to configure custom planning groups, kinematics solvers (KDL), and execute collision-free Cartesian and joint-space trajectories in RViz2. • Hardware Integration: Established a physical control pipeline utilizing micro-ROS running on an ESP32 to actuate hardware servo motors mapping to virtual joint states.

Technical Challenges Overcome: • Solved micro-ROS serial buffer overflows (Handshake Loops) by optimizing Arduino code and right-sizing JointState message array capacities. • Resolved Command Execution Timeouts in MoveIt by throttling the controller update rate to a stable 25 Hz. • Fixed kinematic divergence between simulation and hardware by debugging joint-name mapping callbacks to handle multi-servo array synchronization.

Technologies Used: ROS 2, MoveIt 2, Gazebo Sim, RViz2, ESP32, micro-ROS, C++ (Arduino), Python, SolidWorks, Xacro/URDF.
